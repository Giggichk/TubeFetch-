# 🎬 TubeFetch

> **Версия:** `v0.0.1 (Alpha / Test Release)`  
> Минималистичный и быстрый инструмент для валидации и скачивания видео с YouTube на базе `yt-dlp`.

---

## 📌 О проекте

**TubeFetch** — это модульная утилита на Python, предназначенная для удобной загрузки видео и аудиоматериалов с YouTube. Проект включает в себя многоуровневую валидацию ссылок (синтаксический regex-анализ и сетевая проверка доступности ролика без старта загрузки) с интеграцией cookies из браузера.

> ⚠️ **Внимание:** Это ранняя тестовая сборка (**v0.0.1**). Некоторые функции находятся в активной разработке, возможны изменения в структуре вызовов.

---

## ✨ Текущие возможности

- [x] **Строгая валидация URL:** Проверка форматов `watch?v=`, `youtu.be/`, `shorts/` через регулярные выражения.
- [x] **Проверка доступности (Pre-check):** Анализ доступности видео, проверка на удаление/приватность ролика до начала фактического скачивания (через `extract_info(..., download=False)`).
- [x] **Использование Cookies:** Автоматическое подключение авторизационных сессий и куки (по умолчанию Firefox) для обхода ограничений и скачивания в высоком качестве.
- [x] **Модульная архитектура:** Разделение логики загрузки (`downloads.py`) и верификации (`verifications.py`).

---

## ⚙️ Системные требования

- **Python:** 3.10 или новее
- **FFmpeg:** Рекомендуется для объединения видео/аудио потоков максимального качества (1080p+, 4K) и конвертации в MP3.
  - *Windows:* `winget install Gyan.FFmpeg` или скачать с [ffmpeg.org](https://ffmpeg.org/)
  - *Linux (Ubuntu/Debian):* `sudo apt install ffmpeg`
  - *macOS:* `brew install ffmpeg`

## 🚀 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone -b develop https://github.com/Giggichk/TubeFetch.git
cd TubeFetch
```

### 2. Создание и активация виртуального окружения
```bash
# Windows
python -m venv venv
venv\Scripts\activate

# Linux / macOS
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```
*(Если `requirements.txt` еще не создан: `pip install yt-dlp`)*

### 4. Запуск
```bash
python downloads.py
```

## ⚠️ Текущие ограничения

1. **Привязка к браузеру:** По умолчанию настроен захват сессий из Firefox (`cookiesfrombrowser: ("firefox",)`). Если Firefox не установлен, требуется указать актуальный браузер (Chrome, Edge, Brave) или передавать `cookiefile`.
2. **Сетевые блокировки:** Напрямую зависит от стабильности соединения и доступности серверов YouTube без встроенного автоматического обхода троттлинга/DPI.
3. **Отсутствие CLI-аргументов:** На текущем этапе параметры и целевые ссылки передаются через переменные внутри скрипта.
