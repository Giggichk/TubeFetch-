# TubeFetch 📹
TubeFetch — это легковесное Python-приложение для быстрого скачивания видео и аудио с YouTube. Проект создавался как удобный инструмент, чтобы автоматизировать рутину и моментально получать исходники в максимальном качестве для дальнейшего монтажа и создания контента.
